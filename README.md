# WebRTC Data Channel Starter (Week 1)

## What this repo is
Right now, it only proves one thing: a desktop and a phone can pair 1-to-1 by scanning a QR code and reach a confirmed “connected” state.

## First push
- Set up a local project you can start with `npm install` + `npm start`.
- Made a local page you open on desktop, which shows a QR code.
- When the phone scans the QR, it opens the same page.
- Both devices “meet”, do a quick handshake, and show a clear confirmation on both sides that the connection is established.



## How to run
1. Install dependencies:
   npm install
2. Start the project:
   npm start
3. Open the page on desktop browser (the terminal will show the address/port).
4. Scan the QR code with the phone (same Wi‑Fi network).
5. Wait until both screens say Connected.
